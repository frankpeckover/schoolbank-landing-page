Policy

Privacy

This page explains the types of information handled by Myntix and how schools should expect that information to be used.

Last updated: 5 July 2026

Information we handle

Myntix stores information needed to run a school reward wallet system. This can include names, usernames, email addresses, roles, profile images, groups, timetable assignments, account balances, ledger activity, reward requests, audit records, and security records such as sessions and password reset tokens.

How information is used

Information is used to authenticate users, show the correct student or staff view, record reward currency activity, manage groups and reward requests, support reporting, and keep an audit trail of important actions.

School control

Each school controls the users and activity in its own environment. School administrators are responsible for keeping user details accurate and deciding which staff members should have access to student information.

Access and sharing

Student information should only be available to authorised users who need it for school reward, reporting, or administration workflows. The application should not sell student data or use it for advertising.

Security

The application uses hashed passwords, server-side sessions, role-based access checks, audit logs, and tenant-specific database connections. Operational security also depends on secure hosting, backups, HTTPS, restricted database access, and careful administrator practices.

Contact

Schools should provide a contact point for privacy questions. For hosted environments, the operator of Myntix should also provide a support contact for privacy, export, and deletion requests.
